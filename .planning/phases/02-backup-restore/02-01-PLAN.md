<task type="auto">
  <name>Task 2: Add backup validation and restore functionality</name>
  <files>backend/app/services/backup_service.py</files>
  <action>
Add validation and restore methods to BackupService:

1. **validate_backup method (file_path: Path) -> Dict:**
   - Open tarfile in read mode ('r:gz')
   - Look for 'backup-manifest.json' member - raise ValueError if missing
   - Extract and parse manifest JSON
   - Validate version is "1.0" - raise ValueError if not
   - Return manifest dict for inspection

2. **_validate_tar_member method (member: TarInfo, target_dir: Path) -> None:**
   - SECURITY CRITICAL - follows research patterns
   - Reject if member.name starts with '/' (absolute path)
   - Resolve (target_dir / member.name) and check is_relative_to(target_dir)
   - Reject if not relative (path traversal detected)
   - Reject if member.issym() or member.islnk() (symlink attacks)
   - Raise ValueError with descriptive message on any violation

3. **restore_backup method (file_path: Path, username: str, ip_address: str) -> Dict:**
   - Call validate_backup first to get manifest
   - Open tarfile in read mode
   - For each member (except manifest):
     - Call _validate_tar_member
   - Extract files with proper target paths:
     - Map archived paths back to original locations (e.g., "etc/eco-iot-gw/" -> "/etc/eco-iot-gw/")
     - Use sudo for extracting to system paths
   - Set correct permissions for sensitive files (VPN configs need 600)
   - Log to audit_service: action="backup_restore", resource="system", details with filename and paths
   - Return success dict with message and restored paths

4. **Error handling:**
   - All methods should catch exceptions and log errors
   - Return descriptive error messages in result dicts
   - Never expose internal paths in error messages to clients
  </action>
