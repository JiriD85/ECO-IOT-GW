Create new branding service with:

1. Config storage at `/etc/eco-iot-gw/branding.json`:
   - Load config with defaults if file missing
   - Save config with atomic write (write to temp, rename)

2. Asset storage at `/var/lib/eco-iot-gw/branding/`:
   - save_logo(file_content: bytes, content_type: str)
   - get_logo() -> tuple[bytes, str] or None
   - delete_logo()
   - Same for favicon

3. Kit name update:
   - When kit_name changes with update_wifi_ssid=True
   - Get current wifi config, update SSID, call wifi_service.set_config()

4. Validation:
   - Logo: max 1MB, accept image/png, image/jpeg, image/svg+xml
   - Favicon: max 100KB, accept image/x-icon, image/png
   - Kit name: max 32 chars (WiFi SSID limit)

Structure:
```python
class BrandingService:

    def get_config(self) -> BrandingStatus: ...
    def set_config(self, config: BrandingConfig) -> BrandingStatus: ...
    def save_logo(self, content: bytes, content_type: str): ...
    def get_logo(self) -> Optional[tuple[bytes, str]]: ...
    def delete_logo(self): ...
    def save_favicon(self, content: bytes, content_type: str): ...
    def get_favicon(self) -> Optional[tuple[bytes, str]]: ...
    def delete_favicon(self): ...

branding_service = BrandingService()
```
