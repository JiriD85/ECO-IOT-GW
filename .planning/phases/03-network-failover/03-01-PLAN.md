<task type="auto">
  <name>Task 1: Create NetworkService class with interface monitoring</name>
  <files>backend/app/services/network_service.py</files>
  <action>
Create NetworkService class following established service pattern from ntp_service.py and backup_service.py.

Use psutil for interface status monitoring (following RESEARCH.md Pattern 4):
- psutil.net_if_stats() for operational state (isup, speed, mtu)
- psutil.net_io_counters(pernic=True) for traffic statistics
- Return dict with interface name, is_up, speed_mbps, bytes_sent, bytes_recv

Use subprocess with nmcli for route metric management (following RESEARCH.md Pattern 1):
- nmcli connection show --active for listing active connections
- nmcli connection modify <name> ipv4.route-metric <value> for setting priority
- nmcli connection up <name> to apply changes
- Lower metric = higher priority (Ethernet=100, LTE=200 as defaults per RESEARCH.md)

Implement connectivity health checks (following RESEARCH.md Pattern 2):
- Use subprocess.run() with ping -c 2 -W 3 -I <interface> <gateway>
- Bind to specific interface with -I flag to test that interface (avoid Pitfall 4 from RESEARCH.md)
- Ping multiple targets (1.1.1.1, 8.8.8.8, gateway) to avoid single point of failure (Anti-Pattern 1)
- Return bool success/failure

Use _run_command wrapper pattern for subprocess with sudo support (from ntp_service.py pattern).

Use audit_service for logging all configuration changes (route metric changes, failover events).

Methods to implement:
- get_interfaces() -> List[Dict] - List all network interfaces with status
- get_interface_status(interface_name: str) -> Dict - Detailed status for one interface
- get_active_route() -> Dict - Currently active default route with interface, gateway, metric
- set_interface_priority(interface_name: str, priority: int) -> bool - Set route metric (priority)
- check_connectivity(interface_name: str, target: str) -> bool - Ping health check
- get_failover_config() -> Dict - Current failover configuration (which is primary/backup)
- set_failover_config(primary: str, backup: str) -> bool - Configure primary/backup interfaces

Handle common pitfalls from RESEARCH.md:
- Detect both wwan0 and usb0 for Quectel modem (Pitfall 2)
- Require sudo for nmcli modify commands (Pitfall 6)
- Configure both ipv4.route-metric and ipv6.route-metric (Pitfall 7)

Install required libraries: psutil, pyroute2, netifaces (already in RESEARCH.md standard stack).
