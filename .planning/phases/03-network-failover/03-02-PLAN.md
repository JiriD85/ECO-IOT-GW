```

Implement endpoints:

1. GET /api/network/status - Get current network status for all interfaces
   - No authentication required (read-only status)
   - Calls network_service.get_interfaces()
   - Returns NetworkStatusResponse with list of interfaces, active route, timestamp

2. GET /api/network/interfaces/{interface_name} - Get detailed status for one interface
   - No authentication required (read-only)
   - Calls network_service.get_interface_status(interface_name)
   - Returns NetworkInterfaceDetail with stats, metrics, operational state
   - Raises 404 if interface not found

3. GET /api/network/failover/config - Get current failover configuration
   - Requires authentication (any authenticated user can view)
   - Calls network_service.get_failover_config()
   - Returns FailoverConfig with primary, backup interface names, health check settings

4. PUT /api/network/failover/config - Configure failover priority
   - Requires admin role (uses require_admin from backup.py pattern)
   - Body: FailoverConfigRequest with primary, backup interface names
   - Calls network_service.set_failover_config(primary, backup)
   - Returns success message
   - Raises 400 if invalid interfaces, 403 if not admin

5. POST /api/network/connectivity/test - Test connectivity on specific interface
   - Requires authentication (any user can test)
   - Body: ConnectivityTestRequest with interface name, optional target IP
   - Calls network_service.check_connectivity(interface, target)
   - Returns ConnectivityTestResponse with success, latency, packet_loss

Error handling:
- Catch exceptions from network_service
- Return appropriate HTTP status codes (400 for validation, 404 for not found, 500 for service errors)
- Log errors with logger.error()

Follow patterns from ntp.py:
- Config changes require admin role
- Status/read operations accessible to authenticated users
- Audit logging happens in service layer, not API layer

# Network interface status
class NetworkInterface(BaseModel):
    """Single network interface status"""
    name: str
    is_up: bool
    speed_mbps: Optional[int] = None
    mtu: int
    bytes_sent: int
    bytes_recv: int
    ipv4_address: Optional[str] = None
    gateway: Optional[str] = None
    route_metric: Optional[int] = None

class ActiveRoute(BaseModel):
    """Currently active default route"""
    interface: str
    gateway: str
    metric: int

class NetworkStatusResponse(BaseModel):
    """Overall network status"""
    interfaces: List[NetworkInterface]
    active_route: Optional[ActiveRoute] = None
    timestamp: str

class NetworkInterfaceDetail(NetworkInterface):
    """Detailed interface status with additional stats"""
    packets_sent: int
    packets_recv: int
    errors_in: int
    errors_out: int
    drops_in: int
    drops_out: int

# Failover configuration
class FailoverConfig(BaseModel):
    """Current failover configuration"""
    primary_interface: str
    backup_interface: str
    primary_metric: int
    backup_metric: int
    health_check_enabled: bool
    health_check_interval: int  # seconds
    ping_targets: List[str]

class FailoverConfigRequest(BaseModel):
    """Request to configure failover"""
    primary_interface: str
    backup_interface: str
    primary_metric: Optional[int] = 100  # Default from RESEARCH.md
    backup_metric: Optional[int] = 200   # Default from RESEARCH.md

    @field_validator('primary_interface', 'backup_interface')
    @classmethod
    def validate_interface_name(cls, v: str) -> str:
        """Validate interface name (prevent injection)"""
        if not re.match(r'^[a-zA-Z0-9_-]+$', v):
            raise ValueError('Invalid interface name')
        return v

    @field_validator('primary_metric', 'backup_metric')
    @classmethod
    def validate_metric(cls, v: Optional[int]) -> Optional[int]:
        """Validate route metric range"""
        if v is not None and (v < 0 or v > 1000):
            raise ValueError('Metric must be between 0 and 1000')
        return v

# Connectivity testing
class ConnectivityTestRequest(BaseModel):
    """Request to test connectivity"""
    interface: str
    target: Optional[str] = "8.8.8.8"  # Default ping target

    @field_validator('interface')
    @classmethod
    def validate_interface_name(cls, v: str) -> str:
        if not re.match(r'^[a-zA-Z0-9_-]+$', v):
            raise ValueError('Invalid interface name')
        return v

class ConnectivityTestResponse(BaseModel):
    """Result of connectivity test"""
    success: bool
    interface: str
    target: str
    latency_ms: Optional[float] = None
    packet_loss: float
    timestamp: str
```
