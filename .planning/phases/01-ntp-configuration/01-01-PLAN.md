**Config file handling:**
- Default chrony config path: `/etc/chrony/chrony.conf`
- Parse existing config to extract servers, pools, and key settings
- Write config with user-specified servers/pools while preserving critical settings

**Critical chrony settings to preserve/add:**
- `makestep 1 3` - For offline boot (Pitfall 1: RPi has no battery-backed RTC)
- `iburst` on all servers - Fast initial sync (Pitfall 5: LTE instability)
- `maxpoll 10` - More frequent checks for unstable connections
- `rtcsync` - Keep hardware RTC in sync if present
- `driftfile /var/lib/chrony/drift` - Standard drift file

**Methods to implement:**
```python
class NTPService:
    def __init__(self):
        self.config_path = Path("/etc/chrony/chrony.conf")
        self.backup_path = Path("/etc/chrony/chrony.conf.bak")

    async def get_config(self) -> dict:
        """Parse chrony.conf, return {servers: [], pools: [], settings: {}}"""

    async def set_config(self, servers: List[str], pools: List[str]) -> bool:
        """Write new config, backup old, restart chrony"""

    async def get_status(self) -> dict:
        """Run chronyc tracking, parse output for sync status"""

    async def get_sources(self) -> List[dict]:
        """Run chronyc sources -v, parse NTP source details"""

    async def restart_service(self) -> bool:
        """Restart chrony via systemctl"""

    def _run_command(self, cmd: List[str], sudo: bool = False) -> Tuple[str, str, int]:
        """Subprocess wrapper with optional sudo"""
```

**Subprocess execution:**
- Use `subprocess.run()` with `capture_output=True, text=True`
- For privileged commands (write config, restart service): `sudo=True`
- Return stdout, stderr, returncode tuple

**Audit logging:**
- Import audit_service, log all config changes with action="ntp_config_update", resource="ntp"
- Include old and new server lists in details

**Error handling:**
- Wrap subprocess calls in try/except
- On config write failure, restore from backup
- Return meaningful error messages
