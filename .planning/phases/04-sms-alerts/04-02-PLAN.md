<task type="auto">
  <name>Task 1: Create SMS API Router</name>
  <files>backend/app/api/sms.py</files>
  <action>
Create sms.py router following ntp.py and network.py patterns:

1. **Imports**:
   - FastAPI: APIRouter, Depends, HTTPException, Request, status
   - Models: SMSConfig, SMSRecipient, SMSTrigger, SMSTestRequest, SMSTestResponse, SuccessResponse, UserInfo
   - Security: get_current_user
   - Services: audit_service, sms_service, modem_service
   - From sms_service: validate_phone_number
   - Standard: logging, datetime

2. **get_client_ip(request)** helper (copy from ntp.py)

3. **GET /config** endpoint:
   - Requires any authenticated user
   - Returns SMSConfig from sms_service.get_config()
   - Handle exceptions with 500 response

4. **PUT /config** endpoint:
   - Requires admin role (check user.role != "admin", return 403)
   - Accepts SMSConfig body
   - Validate all phone numbers using validate_phone_number() before saving
   - Call sms_service.set_config() with username and client_ip for audit
   - Return SuccessResponse
   - Handle ValueError (invalid phone) with 400 response

5. **POST /recipients** endpoint:
   - Requires admin role
   - Accepts SMSRecipient body
   - Validate phone number, normalize to E.164
   - Call sms_service.add_recipient()
   - Return SuccessResponse with "Recipient added" message

6. **DELETE /recipients/{name}** endpoint:
   - Requires admin role
   - Call sms_service.remove_recipient(name)
   - Return SuccessResponse

7. **POST /validate-number** endpoint:
   - Requires any authenticated user
   - Accepts phone: str and region: str (default "CZ") as query params
   - Use validate_phone_number() and phonenumbers library for detailed response
   - Return {"valid": true, "e164": "+420...", "country": "CZ", "international": "+420 777 123 456"}
   - Handle ValueError with 400 and {"valid": false, "error": "..."}

8. **POST /test** endpoint:
   - Requires any authenticated user (testing should be accessible)
   - Accepts SMSTestRequest body
   - Validate phone number
   - Generate message if not provided: "Test SMS from ECO-IOT-GW at {timestamp}"
   - Call modem_service.send_sms(validated_phone, message)
   - Audit log the test attempt (success or failure)
   - Return SMSTestResponse

9. **GET /triggers** endpoint:
   - Requires any authenticated user
   - Return list of available trigger types with descriptions:
     - vpn_down: "VPN connection lost"
     - modem_down: "LTE modem disconnected"
     - network_failover: "Network failover occurred"
     - backup_failed: "System backup failed"

Create router with prefix="" (will be mounted at /api/sms in main.py).
