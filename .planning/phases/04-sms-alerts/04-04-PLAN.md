<task type="auto">
  <name>Task 2: Create SMS Alert Daemon</name>
  <files>backend/app/services/sms_alert_daemon.py</files>
  <action>
Create sms_alert_daemon.py following failover_daemon.py pattern:

1. **Docstring and imports**:
   ```python
   """
   ECO-IOT-GW SMS Alert Daemon
   Monitors system events and sends SMS alerts to configured recipients.

   Trigger Events:
   - vpn_down: VPN tunnel disconnected
   - modem_down: LTE modem unreachable
   - network_failover: Network failover occurred
   - backup_failed: Backup operation failed

   Features:
   - Configurable cooldown per trigger
   - Multiple recipients support
   - Graceful shutdown on SIGTERM/SIGINT
   """
   import asyncio
   import logging
   import sys
   from pathlib import Path
   from datetime import datetime
   from typing import Dict, Optional
   ```

2. **Path setup for standalone execution**:
   ```python
   sys.path.insert(0, str(Path(__file__).parent.parent.parent))

   from app.services.sms_service import sms_service
   from app.services.modem_service import modem_service
   from app.services.audit_service import audit_service
   ```

3. **Configuration constants**:
   ```python
   CHECK_INTERVAL = 60  # seconds between checks
   VPN_CONFIG_PATH = Path("/etc/eco-iot-gw/vpn/")
   ```

4. **SMSAlertDaemon class**:
   - `__init__`: Initialize logger, running flag, previous states dict
   - `_check_vpn_status() -> bool`: Check if any VPN is expected but down
   - `_check_modem_status() -> bool`: Check if modem is responding (AT+CPIN?)
   - `_check_failover_state() -> Optional[str]`: Check if failover occurred (read state file)
   - `_check_backup_status() -> Optional[str]`: Check for recent backup failures (audit log)

5. **_send_alert(event_type: str, message: str) method**:
   - Check if SMS enabled in config
   - Check cooldown for event_type
   - Get enabled recipients
   - For each recipient: call modem_service.send_sms()
   - Record trigger fired
   - Audit log the alert

6. **_evaluate_triggers() method**:
   - Check each trigger condition
   - If condition changed from OK to FAILED: send alert
   - Track previous states to detect transitions (not continuous alerts)

7. **monitor_loop() method** (async):
   - Load config
   - While running: _evaluate_triggers(), sleep(CHECK_INTERVAL)

8. **main() async function**:
   - Configure logging (console + /var/log/eco-iot-gw/sms-alerts.log)
   - Create daemon, run monitor_loop
   - Handle KeyboardInterrupt

9. **Entry point**: `if __name__ == "__main__": asyncio.run(main())`
